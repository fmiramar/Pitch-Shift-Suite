# A08 — OCEANOctave

**Evidence:** published equations, author convention notes and local measurements. **Phase:** 4. **State:** standalone/SC diagnostic implementation delivered; general pitch accuracy and exact thesis reproduction are not established.

**Source:** [Thuillier 2016](https://aaltodoc.aalto.fi/bitstreams/ff9e52cf-fd79-45eb-b695-93038244ec0e/download), §4.2.1 equations (17)–(18), §6.5/Table 7. This is the thesis's octave-specific version of the OCEAN family also studied in A16.

**API:** `OCEANOctave.ar(in)`, mono, fixed nominal octave-up operation. N=897, R=224; fixed sample counts at every rate. No ratio, octave-down, formant, stereo-linking or A16 demodulation controls. Constructor prepares all storage; process/reset are bounded and support exact in-place buffers. Nonfinite input becomes zero.

**Equation/sign trace:** the printed (17) maps j→2j with a negative rotation. [OCEANOctave.hpp](../../src/dsp/OCEANOctave.hpp), `translate`, uses `X[j]·exp(+i2πja/N)` for frame start a=mR with our chronological, negative-exponent forward DFT. A bin-centered tone has analysis phase Ωj a, so destination 2j needs phase 2Ωj a. Conjugating the spectrum convention reverses the sign. The author's [reference archive](https://pitchtech.ch/Confs/ICALIP2010/PitchShiftOcean.7z), `fixSpectrum` comments, explicitly discusses reversing the rotation for another FFT convention. This is a documented convention adaptation; the thesis's exact implementation is unavailable. No Java code or A16 features were imported.

**Numerical resolution:** independent NumPy experiments (development record retained separately) compare native-positive, literal-negative and four-frame rotations with the same 897-point DFT. The literal sign fails the odd-bin-center tuning test here (about +95.66 cents for bin 9). Exact N/R is selected; substituting N−1 only in the rotation adds about one cent at bin centers. Window N versus endpoint span N−1 remains explicit: the symmetric Hann spans 896 samples with 897 coefficients and exactly 1.5 summed squared overlap weights. Its DFT has 897 bins, computed by private Bluestein convolution at length 2048. No silent FFT-length rounding occurs.

**Streaming/boundaries:** frames finish at clock=0,R,2R,…, begin at a=clock−896 and are read in chronological order. Rotation stores `a mod 897`, initially 1, incremented by 224; its exact period is 897 frames. It uses prepared unit roots, with no accumulating float phase. Positive bins 1–224 map injectively to even destinations 2–448; positive odd destinations remain zero. Higher source bins are discarded, DC stays signed real and negatives are conjugate-mirrored. Odd N has no singleton Nyquist bin. Finite-window leakage at the cutoff remains possible; the mapping does not fold high bins back. There are no destination collisions for this factor-two mapping.

**Synthesis/delay:** inverse DFT, symmetric Hann, overlap-add divided by the unmodified WOLA weight 1.5. This does not correct the transformed-window amplitude modulation: even steady DC is modulated. Contributions are scheduled from clock through clock+896, so 2048 ring slots suffice. The reference WOLA alignment is 896 samples, not a fixed onset/peak latency for the shifted output. Response timing depends on input position and phase epoch.

**Observed behavior:** at 44.1 kHz, 110 Hz→208.34 Hz (target 220; −94.25 cents), 454.766→897.256 Hz (target 909.532; −23.53 cents). Bin-center tones tune correctly but only about 88.8% of their steady energy is coherent at the target. The reference impulse has strong lobes at 642 and 1090 samples; the second is only −1.96 dB below the first. Native lobe separation is about N/2, while the literal-sign control has R-spaced images closer to the thesis plot. This discrepancy is retained, not described as exact reproduction. No general-quality or POG-similarity claim.
