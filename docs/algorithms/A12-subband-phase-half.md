# A12 — SubbandPhaseHalf

**Evidence:** experimental, with analytic counterexamples and measured implementation. **Phase:** 5. **State:** independent experimental standalone/SC UGen; general polyphonic branch recovery is unresolved.

**Source basis:** the project's proposed experiment; [Thuillier Table 3](https://aaltodoc.aalto.fi/bitstreams/ff9e52cf-fd79-45eb-b695-93038244ec0e/download) motivates phase scaling but does not validate polyphonic octave down. [Terrarium BandShifter](https://github.com/schult/terrarium-poly-octave/blob/bc7ddf35362cf4b0e9d46b77bc21e490f79f9ed1/util/BandShifter.h) supplies a separate branch-tracking comparison. Its negative-axis predicate is modeled in tests with exact arithmetic, retaining the [MIT notice](../../tests/licenses/terrarium-MIT.txt); its approximate square roots/filterbank are not ported. A13 is not implemented by this checkpoint.

**Model, not a verified published algorithm:** for `z=A exp(iφ)`, track unwrapped phase Φ and synthesize `A cos(Φ/2)`. Native code stores `θ=Φ/2 mod 2π`, preserving full-phase turn parity without an ever-growing accumulator. On consecutive reliable samples, `θ ← wrap(θ + wrap(φ−φ_previous)/2)`, with wrap in `[−π,π)`. This is phase unwrapping followed by division, not independent principal square roots. The Python oracle independently lifts each principal phase onto an unbounded full-phase trajectory.

The analysis bank is exactly the A05 coefficient construction (43 repeated-pole complex filters), chosen as a controlled starting point, **not** a published octave-down preset. The [A05 pole/gain derivation and response plots](A05-erb-phase.md) apply; no coefficients, tests or implementation in A05/A06 were changed. Real synthesis is twice the sum of per-band outputs, using the same real-input gain convention.

**Reliability policy:** each band keeps a peak envelope with instantaneous attack and 50 ms exponential decay. Reliability is lost at `A ≤ max(1e−12, peak·1e−4)` and regained above twice that threshold. Unreliable output is zero; the initialized half-phase advances at half the nominal band-center frequency. Recovery selects the measured phase branch nearest that prediction and fades amplitude back over about 1 ms. This is a stated heuristic: it cannot know how many turns occurred while the band was unreliable. Filter state components below `1e−30` are cleared as in A05; the reliability envelope is also cleared below `1e−30` to avoid denormal decay during long silence.

At first activation, the half-phase starts at `φ/2`; if the immediately lower band is reliable, its sign is chosen to put the two half-phases within π/2. This affects only initial branch choice. Running bands are never sign-flipped to follow neighbors. Reset clears phase, envelope and filter histories. In the measured ordinary 440 Hz startup, this anchoring made **zero difference** because the bands began on the same real-input branch. An isolated joining-band test verifies the sign choice, but no continuing interband-coherence solution is claimed.

**API:** `SubbandPhaseHalf.ar(in)`, experimental **0.5× / −12 semitones only**. Analysis centers 81.976–3936.367 Hz imply nominal half-frequency centers 40.988–1968.184 Hz. This is not a full-band arbitrary-ratio engine. Constructor range22.05–192 kHz, block≤4096; audio tests44.1/48/96 kHz. Quarter-frequency output is deferred.

**Analytic results and counterexamples:** one million native samples of a complex440 Hz sine give half-phase cosine error <1.13e−13 and maximum adjacent step0.002880 at amplitude0.1/48 kHz. A matched-center gap recovers that particular branch after the fade. The principal half-angle cosine has RMS error0.1 against the amplitude0.1 ideal; it is rectified instead of preserving the required sign. The Terrarium crossing-rule control works on the steady positive-frequency sine, but flips the wrong sign on principal phases0.4→−2.0, a negative increment smaller than π that does not cross the cut. This is a rule counterexample for abrupt/negative phase motion, not a full Terrarium audio-quality result.

A stronger counterexample inserts one full phase turn inside an interval whose amplitude is zero. The two observed complex signals agree to <9.22e−15, while their ideal half-phase outputs after the gap have opposite polarity. No deterministic observation-only method can distinguish them. A12 remains a heuristic even when finite-output and selected pitch/continuity tests pass.
