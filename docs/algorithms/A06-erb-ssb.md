# A06 — ERBSSBOctave

**Evidence:** published equations + numerical/audio measurements. **Phase:** 5. **State:** standalone/SC diagnostic reference implemented; not a generally accurate octave shifter.

**Source:** [Thuillier 2016](https://aaltodoc.aalto.fi/bitstreams/ff9e52cf-fd79-45eb-b695-93038244ec0e/download), §5.1 Table 3; Figure 15/Table 5; equations (37)–(40); §6.4 Table 6. Existing verified local PDF inspected. Original implementation, no author/reference code imported.

**Equation trace:** Table 6 gives `qPS=1, qERB=12, qC=8, zleft=5, BW_ERB=28, K=43`. Centers and analysis widths agree with A05 because `qC/qERB=2/3` and `qPS·qERB=12`. The [A05 pole/gain derivation](A05-erb-phase.md) applies unchanged: `H_k(z)=g_k(1−z⁻²)/(1−p_k z⁻¹)²`, positive real center normalization, zeros ±1 and repeated positive-frequency pole. Native coefficient expressions are reused in the independent A06 engine; exact coefficient equality with the untouched A05 engine is tested at 22.05/44.1/48/96/192 kHz. No generalized bank abstraction was introduced.

Table 3 SSM2 gives `y[n] = 2 Σ_k Re(z_k[n] exp(i·2π fc[k] n/f_s))`. The factor 2 retains A05's compensation for the half-amplitude positive-frequency component of real input; it is an explicit gain convention, not a recovered author coefficient file. The complex oscillator starts at 1 on the engine's first processed sample, multiplies by `exp(i·2π fc/f_s)` each sample, and normalizes its radius every 1024 samples. The counter persists across callbacks and advances during silence. Reset clears filter histories and resets every oscillator to 1. No frequency estimator, phase scaling or per-block phase reset is used.

**API:** `ERBSSBOctave.ar(in)` is a fixed **nominal** octave-up reference. In band k a tone `f` becomes `f+fc[k]`, with error `fc[k]−f` relative to `2f`. Only a band's center is exactly doubled in that band's contribution. Adjacent filters produce other translated copies; finite negative-frequency leakage also produces difference components. Octave down and general ratios are unsupported. Construction accepts 22.05–192 kHz/blocks up to 4096; audio checks cover 44.1/48/96 kHz.

**Measured distinction from A05:** at 44.1 kHz, 110 Hz produces a dominant 222.415 Hz (+18.90 cents), while 440 Hz produces 864.121 Hz (−31.52 cents). A05 gives 220/880 Hz on those inputs. At the selected 443.971 Hz analysis crossover, A06 produces strong components at 868.093 and 908.332 Hz, separated by 40.239 Hz. A05 instead retains a dominant 887.943 Hz component, but with severe gain cancellation and only about 82.2% coherent target energy in this additional probe. Neither comparison establishes clean polyphony.

For that shared crossover tone, steady-state Hilbert-envelope coefficient of variation is 0.4688 for SSM2 and 0.1671 for PS2. For a 440/445 Hz pair it is 0.6380 versus 0.3622; for the selected six-tone chord, 0.4624 versus 0.4417. These are **envelope-variation proxies**, not perceptual roughness or listening scores. SSM is linear time-varying apart from the negligible `1e−30` state floor: it creates translated copies, not nonlinear intermodulation between inputs. The numerical linearity residual is <1.50e−8; PS2's modulation is nonlinear.

Target crossover envelopes are evaluated as `|H_k(F−fc[k])|`. Their intersections measure −24.55…−25.43 dB at 44.1 kHz, compared with Table 6's approximate −24 dB. The identical analysis bank still has A05's −13.97…−14.68 dB crossover discrepancy versus the thesis's −12 dB. Existing A05 per-filter magnitude/phase/group-delay plots apply to this identical bank; a new crossover audio comparison is generated under `build-a06/reference/`.

**Latency and safety:** analysis-filter center group delays remain 4.60–90.03 ms at 44.1 kHz. Oscillator phase makes impulse response depend on arrival epoch: impulses at samples 0/1234/22050 peak after 170/192/94 samples, with 99%-energy times after 3119/3167/3252 samples. There is no single fixed impulse delay. Fifteen one-million-step oscillator probes have maximum complex error <1.54e−10 and radial error <5.73e−14 against direct exponentials. Processing/reset allocate no ordinary C++ memory in the smoke test; SC preparation/disposal uses the existing worker lifecycle.

There is no oversampling or post-filter. A 23 kHz input at 48 kHz makes 18 positive-image band contributions exceed Nyquist. Predicted aliased-only energy is −95.90 dB relative to input; the strongest folded component at 21063.63 Hz measures amplitude 6.16e−7 for input amplitude 0.1. This demonstrates small but nonzero aliasing, not alias-free operation.
