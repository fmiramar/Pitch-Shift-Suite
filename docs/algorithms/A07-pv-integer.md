# A07 — PVIntegerOctave

**Evidence:** published equations, independent numerical reference and local audio measurements. **Phase:** 4. **State:** functional standalone/SC checkpoint implemented; exact thesis reproduction and extended quality/RT gates remain open.

**Source:** [Thuillier 2016](https://aaltodoc.aalto.fi/bitstreams/ff9e52cf-fd79-45eb-b695-93038244ec0e/download), §4.2.2 equations (19)–(32), §6.5 Figure 21/Table 7. Laroche–Dolson integer-factor discussion is the supporting origin.

**Equation trace:** with the specified initialization, integer `γ` makes the unwrapping contribution a multiple of `2π`, giving synthesis phase `γ·arg(X)`. For γ=2, equation (31) is `Y=X²/|X|`. In [PVIntegerOctave.hpp](../../src/dsp/PVIntegerOctave.hpp), `doublePhase` implements this with a zero-magnitude guard. `transformFrame` uses centered analysis/synthesis origins, and `renderFrame` realizes synthesis hop 2R followed by 2:1 decimation, leaving final hop R. There is no phase-unwrapping accumulator.

**API:** `PVIntegerOctave.ar(in, windowSize=1169)`. Fixed octave up, mono, initialization-only size 1169 or 1161, hop R=16. No ratio input: octave down, fractional ratios and +24 are unsupported. The standalone constructor takes sample rate (8–192 kHz accepted; 44.1/48/96 kHz tested) and maximum callback size (1–4096). Window lengths stay fixed in samples at other rates; they are not constant-duration presets.

**Conflicting source conventions:** Table 7's 1169 is the default; §8's 1161 is a labeled alternative. Substitution into printed equation (41) yields 1160 before an odd-length choice, consistent with 1161 but not an explanation for 1169. Neither text is silently corrected. We use the standard symmetric Hann `w[j]=0.5−0.5 cos(2πj/(N−1))`, with zero endpoints, rather than Table 1's swapped Hann/Hamming labels. The source does not fully specify FFT/resampler details; these decisions define this implementation, not a claim of identical unpublished code.

**Exact transform and phase origin:** the FFT is the actual odd N-point DFT. Private Bluestein convolution uses the existing MIT portable FFT at length 4096; it does not change the transform's frequency grid. Its chirp identity is checked against direct DFT values and inverse reconstruction. With `C=(N−1)/2`, input sample offset n from the frame center is stored at index `n mod N`; inverse output is read with the same convention. A centered impulse at d therefore moves to `2d mod N` before decimation. Circular wrap explains why small echo images can survive centering. An independent NumPy experiment without the origin shifts produces two strong lobes.

**Resampling and gain:** apply the synthesis Hann, a DC-normalized 65-tap Blackman-windowed sinc lowpass (cutoff 0.24 cycles/input sample), then sample at offsets 2j. Retain linear-convolution tails with zero outside the frame. This project-specific decimator attenuates frequencies approaching the original quarter-rate boundary; it is not an ideal brick-wall filter. Preparation computes the processed unit-DC frame and its 16 overlap residue sums; output divides by that fixed periodic gain. This accounts for the envelope change caused by phase doubling and prevents startup normalization spikes. It calibrates DC, not arbitrary musical loudness.

**Causality/endpoints:** with FIR radius L=32, output extent `J=(C+L)/2`, frame center c and delay `D=C+J`, contributions are written to `c+D+j`, `−J≤j≤J`. The earliest contribution is the current sample and the latest is C+L samples ahead; the fixed 2048-slot output ring suffices. No additional host-block delay is imposed. DC follows phase doubling (`negative DC → positive DC`); odd N has no singleton Nyquist bin. Conjugate symmetry is enforced, and the decimator rejects the doubled high band. Nonfinite input becomes zero; reset clears state without allocation. Exact input/output aliasing and irregular callback partitions are tested; partial buffer overlap is unsupported.

**Measurements:** checkpoint (development record retained separately). Both lengths pass selected octave pitch tests, all 16 impulse positions, independent NumPy comparison, Release/sanitizer and SC/live checks. Default impulse delay is 892 samples (20.227 ms at 44.1 kHz); alternative 886 (20.091 ms). Echoes occur about 13 ms before/after at approximately −31.45 dB, differing from the thesis's roughly −40 dB. At 96 kHz/110 Hz, the fixed 1161-point window fails the initial 98% target-energy purity threshold (97.9% measured); basic pitch acceptance passes. Dense chords can generate substantial extra spectral energy. No artifact-free, perceptual-quality or POG-similarity claim.

**Realtime/license:** FFT/buffers/calibration on the worker; fixed bounded processing with zero observed ordinary C++ process/reset allocations. Observed offline wall/audio ratios about 0.21–0.24 at 44.1/48 kHz and 0.46 at 96 kHz on Apple M5, including setup; these are not callback deadlines or OS CPU-utilization measurements.
