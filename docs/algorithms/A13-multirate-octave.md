# A13 — MultirateOctaveShift

**Evidence:** usable source + measured port; **derived phase-scaling variant**. **Phase:** 6 per AGENTS.md. **State:** independent standalone/SC functional checkpoint, fixed 48 kHz. Scientific/release gates remain open.

**Source/license:** [Terrarium](https://github.com/schult/terrarium-poly-octave/tree/bc7ddf35362cf4b0e9d46b77bc21e490f79f9ed1), MIT, copyright 2024 Steven Schulteis. `main.cpp`, `OctaveGenerator`, `BandShifter`, `Multirate`, `FastSqrt`, README and LICENSE inspected; hashes match Phase0. **Equation/source trace:** `OctaveGenerator` builds 80 bands with `f_k=480·2^(0.027k)−420`. `BandShifter` explicitly cites Thuillier for `z(z/|z|)^(γ−1)`. Up-one computes `Re(z²)/|z|` using approximate inverse square root. Down-one follows complex half-angle expressions and a sign toggled on negative-real-axis crossings; down-two repeats branch handling. Its RBJ/Noga modulated-lowpass filter construction differs from A05's thesis construction. A13 is not independent evidence of a new phase-scaling principle.

**API:** `MultirateOctaveShift.ar(in, voice=0)`, scalar initialization-only voice: **0 = +12**, **1 = −12**, **2 = −24 semitones**. One output per instance. **48 kHz only**; invalid configuration outputs silence in SC and throws during standalone preparation. No arbitrary ratios or other sample-rate extrapolation. Analysis centers span60–1685.418 Hz, bandwidths8.983–39.402 Hz at8 kHz. The source designs an approximately0–1800 Hz input passband and0–3600 Hz reconstruction passband, with substantial ripple; these are source design comments, not a flat full-bandwidth claim.

**Source-to-code trace:** `Multirate.hpp` preserves all source FIR coefficients, polyphase ordering and history offsets. Decimation is48→16→8 kHz; interpolation is8→16→48 kHz. Source ring index0 is newest; an independent fixed-array history implements that convention. The offsets (11/1 for decimation,7/5 for interpolation) are retained. The host adapter collects six samples and emits the reconstructed group during the next six samples, adding a defined six-sample causal delay and supporting arbitrary callback sizes.

`BandShifter.hpp` retains the modulated lowpass biquad: `w0=π·bw/8000`, `a0=1+sqrt(2)sin(w0)/2`, `g=(1−cos(w0))/(2a0)`, `d=[g,2g exp(iw1),g exp(2iw1)]`, `c=[−2cos(w0)exp(iw1)/a0,(1−sqrt(2)sin(w0)/2)exp(2iw1)/a0]`. Modulation and both negative-axis sign trackers follow the source. This is a different filter from A05/A12's repeated-pole bank. It inherits the crossing-rule limitations documented in A12.

**Explicit adaptations:** fixed storage and prepare-time initialization replace callback-local construction/vector allocation; reset clears all histories and signs. `std::pow` replaces gcem for center preparation; no embedded-firmware bit-identity claim. C++17 bit copies retain the approximate inverse square root. Its measured worst relative error is0.00065013; real-axis normalization can produce a half-angle radicand as low as−0.00032506. The port clamps square-root radicands to zero and returns zero inverse magnitude below1e−30. Float filter-state/input values below1e−15 are cleared to avoid denormal tails; this intentionally changes extremely quiet behavior. Input is finite-sanitized and limited to±1e6 to prevent float overflow. Firmware shelves (−11 dB high shelf at140 Hz, +5 dB low shelf at160 Hz), dry mix and controls are omitted. Raw source voice gain is retained; no extra factor2 is added.
