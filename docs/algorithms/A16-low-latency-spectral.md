**Paper → source → code trace:**

- §3.2 equation(1), §3.4 padded extension → `processSpectrum()` → `renderFrame()`: source bin a maps to b=floor(m·r·a+0.5); out-of-range bins are discarded, contributions accumulate and DC is copied. The selected range has no destination collisions because m·r≥2.
- Equation(2), its unnumbered padded extension on PDF p3, and erratum → phase exp(−i·2π(b−ma)p/(mO)) in Java. The printed extra N denominator is removed in both forms, as in the source. Java comments call the padded forms equations(4)/(5); those numbers do **not** match this PDF (equation4 is a later trigonometric identity). Correspondence is by formula and section.
- `fixSpectrum()` documents the sign convention. BooFFT's real analysis is conjugated relative to the portable FFT; C++ therefore uses **positive** rotation with exp(−iωn) analysis. BooFFT's forward2/N and half-unscaled inverse combine to1/N. C++ full-complex inverse is divided by **N, not mN**, then cropped to N (§3.4).
- §§3.5–3.6 → `getModifiedAnalysisWindow()` / `getDemodulationWindow()` → `integerWindow()`, `modifiedWindow()` and constructor table: retain discrete index floors, interpolate the two neighboring integer padded ratios, sum eight transformed Hann products, and divide by max(0.1, sum). One32-hop cycle is precomputed. Processing does no heap allocation or logging.
- Source starts p=−7 and reports latency0 deliberately, despite its N−H comment. The arbitrary-block FIFO adds H: measured unity delay is **512 samples**. Real-IFFT endpoint treatment is preserved, including increased gain when input Nyquist moves to an interior bin. Double arithmetic replaces Java float; sample-exact Java reproduction is not claimed.
