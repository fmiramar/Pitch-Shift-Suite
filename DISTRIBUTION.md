# Distribution scope

This is a source-only research release prepared locally on 2026-11-08. It has not been published. Include LICENSE, LICENSES.md, NOTICES.md, the third-party notices and the source manifests when redistributing it. The outer development repository and its Git history are not part of this release.

A binary distribution is a separate artifact. Before distributing binaries, make the complete corresponding source for those binaries available through a GPL-compliant method. Supply the exact project revision, modifications, build/install scripts, vendored source and non-system dependency sources used (including the required SuperCollider headers and optional pinned Rubber Band sources), with their upstream notices. A collection of binary files and license texts alone is insufficient. The supplied CMake install copies license notices, but does not construct that corresponding-source distribution.

Download links and pins here support reproducible development; do not assume that an upstream URL alone discharges your source-delivery obligations. No binary or SDK is included in this archive. Keep external dependency/build/stage folders out of a source-only export.

No scientific papers, unlicensed author reference recordings, music excerpts, capture-derived renders, author plugin/JAR binaries, copied manufacturer graphics, Gemini conversations, or development Git history are included. Four CC0 piano/guitar demonstration arrangements are included, with original source URLs, hashes and dedication texts. These are separate from the excluded POG recordings. The Phase 8 fitted candidate and its capture tools remain in the private working repository pending separate provenance/use review. Its deferral is a conservative scope choice, not a finding that its DSP parameters are unlawful.

Third-party product names are used only as source/dependency references. This project has no affiliation with or endorsement by Electro-Harmonix, MixWave or the cited researchers and manufacturers. No original-pedal firmware or licensed commercial plugin code is included.

This file records a concrete licensing/package review, not a legal opinion or freedom-to-operate determination. No patent search or jurisdiction-specific clearance has been completed. Technical tests likewise do not certify broad audio quality or all real-time safety conditions. Those limits remain documented in the help and source sheets.
